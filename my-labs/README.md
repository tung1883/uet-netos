# My lab submissions (Lab3–Lab8)

Real completed lab work for INT3301 (Thực hành Hệ điều hành mạng), submitted via the UET-LMS portal. Each folder has:

- `assignmentN.md` → `assignment.md`: the official assignment instructions, crawled from the portal assignment page (course 6560).
- `labN.md` (where present): my own write-up/answers, screenshots referenced inline.
- `labN.pdf` / `labN-light.pdf`: the submitted PDF (with screenshots).
- `commands.md` (where present): the exact commands run during the lab.
- `*.PNG`: terminal screenshots, numbered to match the write-up.
- Scripts/config submitted as part of the lab (e.g. `file_manager.sh`, `user_batch.sh`, `users.csv`, systemd `.service`/`.timer` units).

| Lab | Topic |
|---|---|
| lab3 | Quản lý đĩa và hệ thống tệp (partitions, ext4, mount, LVM, quota) |
| lab4 | Quản lý người dùng, tiến trình và dịch vụ (users/groups, permissions, SGID/sticky bit, ACL) |
| lab5 | Lập trình quản trị và nền tảng dịch vụ mạng (bash networking script, nmcli, routing/DNS, SSH) |
| lab6 | Lập trình Bash cơ bản (`file_manager.sh`) |
| lab7 | Tự động hoá và lập lịch tác vụ (`user_batch.sh`, cron, systemd timer) |
| lab8 | Cấu hình mạng và SSH (Netplan, SSH key auth, SFTP) |

Kept for personal reference, and as real-world grounding for the question bank / reference docs elsewhere in this repo.
